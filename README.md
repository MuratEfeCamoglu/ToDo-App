# 📝 Flutter To-Do App

Bu proje, **Flutter** framework'ü ve **Dart** programlama dili kullanılarak geliştirilmiş, modern ve kullanıcı dostu bir yapılacaklar listesi uygulamasıdır [cite: 58, 60, 114]. Kullanıcıların günlük görevlerini organize etmelerine, kategorize etmelerine ve takvim üzerinden takip etmelerine olanak tanır [cite: 104, 105, 106, 109].

## ✨ Özellikler

* **Görev Yönetimi:** Yeni görevler ekleyebilir, mevcut görevleri silebilir veya tamamlandı olarak işaretleyebilirsiniz [cite: 104, 112].
* **Kategorizasyon:** Görevlerinizi farklı başlıklar altında toplayarak daha düzenli bir yapı oluşturabilirsiniz [cite: 106].
* **Takvim Görünümü:** Görevlerinizi tarih bazlı olarak takvim ekranı üzerinden takip edebilirsiniz [cite: 105].
* **Kullanıcı Profili:** Uygulama içerisinde kişisel bir profil sayfası bulunmaktadır [cite: 109].
* **Modern Arayüz:** Temiz, duyarlı (responsive) ve şık bir tasarım sunar [cite: 107, 108, 112].

## 🛠️ Kullanılan Teknolojiler

* **Framework:** [Flutter](https://flutter.dev/) [cite: 114]
* **Dil:** [Dart](https://dart.dev/) [cite: 114]
* **Platform Desteği:** Android, iOS, Web ve Masaüstü (Windows, macOS, Linux) [cite: 58, 60, 115, 124, 137].

## 📂 Proje Yapısı

Uygulamanın kaynak kodları `lib/` klasörü altında organize edilmiştir [cite: 103]:
* `main.dart`: Uygulamanın başlangıç noktası ve temel yapılandırması [cite: 103].
* `models/`: Veri modellerini içeren klasör (Örn: `task_model.dart`) [cite: 104].
* `screens/`: Uygulamanın ana sayfalarını (Home, Calendar, Profile vb.) barındırır [cite: 105, 106, 107, 109].
* `widgets/`: Uygulama genelinde kullanılan tekrar edilebilir arayüz bileşenleri (Örn: `task_tile.dart`) [cite: 112].

## 🚀 Kurulum

Projeyi yerel ortamınızda çalıştırmak için şu adımları izleyin:

1.  Flutter SDK'nın sisteminizde kurulu olduğundan emin olun.
2.  Gerekli paketleri indirin:
    ```bash
    flutter pub get
    ```
3.  Uygulamayı başlatın:
    ```bash
    flutter run
    ```
